# 簡易點單結算模組

## 定位

本模組提供門店員工進行點單、金額核對、收款找零與打包確認，不取代正式 POS。

## 模組邊界

- `domain/`: 訂單、多客暫存、四品核對、付款、打包與不可刪除事件規則。
- `application/`: 前台唯一操作介面，畫面不直接依賴資料庫。
- `adapters/`: 目前提供開發驗收用 Memory Adapter；正式 Supabase Adapter 尚未啟用。
- `components/`: 手機優先的點單、客人切換、收款及打包介面。

## 上線安全閘門

1. 商品與售價須由總部正式核定，不得直接沿用開發展示價格。
2. 免登入裝置必須由店長或總部產生一次性綁定憑證，前台不得自行選店後直接寫入正式資料。
3. 主管密碼只可在後端驗證並保存雜湊，不得寫入前端程式或瀏覽器儲存。
4. 正式訂單、取消、折扣、改價及作廢事件需寫入 Supabase 並完成 RLS／RPC 驗收。
5. 正式 Adapter 通過後才可由功能開關取代 Memory Adapter。
